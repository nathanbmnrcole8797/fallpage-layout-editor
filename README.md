## What FallPage Does

FallPage provides an HTML-based workspace for composing documents across multiple pages. Its browser-first approach gives users an alternative to conventional desktop publishing software when they need structured page composition, reusable templates, and document preparation tools.

The editor is built around everyday document production tasks. Create and arrange content blocks, define page dimensions, add recurring headers and footers, and prepare the result for PDF export. FallPage is suited to print-oriented documents, repeatable document systems, and layouts that rely on master styling or saved page configurations.

---

## Core Capabilities

- Assemble page content with a block-oriented document editor
- Create flexible compositions using multi-column layouts
- Begin new documents from template presets
- Build a table of contents for longer documents spanning multiple pages
- Choose A4, Letter, Legal, or custom page dimensions
- Apply master headers and footers to recurring page elements
- Export print-focused PDFs directly through the browser
- Automatically save and reload work through IndexedDB storage

   `cd fallpage-multi-page-layout`

## Working with the Editor

1. Create a blank document or select a template preset.
2. Insert content blocks and distribute them across the required pages.
3. Choose a standard page format or enter custom dimensions.
4. Add master headers and footers for elements that should repeat.
5. Generate a table of contents for documents containing several sections.
6. Export the completed layout as a PDF generated by the browser.

A typical editing sequence looks like this:

- Pick a template
- Define the page dimensions
- Modify blocks and columns
- Inspect the composition
- Export the finished PDF

## Local Configuration and Storage

FallPage keeps most document state in the browser through IndexedDB. The local application workflow preserves saved work and settings such as the selected template and page configuration.

Document options are generally managed within the editor itself; a separate configuration file is not normally required.

Example structure:

{
  "pageSize": "A4",
  "layout": "multi-column",
  "template": "preset-name",
  "masters": true,
  "autoSave": true
}

## Frequently Asked Questions

**Can saved documents be opened again?**  
Yes. FallPage persists documents in the browser, allowing them to be reopened in the same environment.

**Where does FallPage keep saved content?**  
The browser stores saved content locally using IndexedDB.

**Are document templates included?**  
Yes. Template presets are available as starting points for new documents.

**How can I update my local copy?**  
Download the latest build from the project page and replace the existing copy.

**Why might PDF export fail?**  
Verify that the browser supports the required features, refresh the application, and make sure the editor has fully loaded before trying the export again.
